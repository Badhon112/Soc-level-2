## What is SIEM ?

- **_SIM + SEM = SIEM_**
  - **SIM = Security Information Management**
    - Data Storage
    - Analyzing data
    - Creating Report
  - **SEM = Security Event Management**
    - Real-Time
    - Monitoring analysis & notification
    - Security Events
  - **SIEM = Security Information and Event Management**
    - Centralized Solution
    - Collecting and Analyzing and Management Data
    - Combined SIM & SEM
    - _Collect, Normalizing and Parsing, Aggregation, Correlation, Analyze_

SIEM is the term used for management system that know how to automatically collect and process information from information from various sources, Stores it in one centralized location, correlate different events, and alerts us
